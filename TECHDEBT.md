## Высокий приоритет

### Локализация обработки персональных данных (152-ФЗ)

**Проблема.** Форма контакта отправляет данные через Formspree (США), сайт хостится на Cloudflare (США). По ст. 18 ч. 5 152-ФЗ операторы, обрабатывающие ПДн граждан РФ, обязаны хранить и первично собирать их на серверах в РФ. Наша текущая архитектура этому не соответствует — риск претензий Роскомнадзора, штраф до 6 млн ₽ за первое нарушение (ст. 13.11 КоАП, редакция 2024+).

**Что нужно исследовать/переделать.**
- Уточнить, применяется ли требование к физическому лицу без ИП/ООО, обрабатывающему единичные обращения (спорная зона — Роскомнадзор трактует расширительно).
- Заменить приёмник форм на локализованный в РФ сервис: [SendPulse](https://sendpulse.com/ru), [UniSender Go](https://unisender.com/ru/), собственный endpoint на VPS в РФ (Selectel, Timeweb, Yandex Cloud), или прямо через SMTP на почтовый ящик в yandex.ru / mail.ru.
- Рассмотреть перенос хостинга на РФ (Selectel Object Storage, Yandex Cloud Object Storage, Timeweb Cloud) — если данные о посетителях (IP, cookies) тоже считать ПДн.
- Разослать «уведомление об обработке ПДн» в Роскомнадзор через [pd.rkn.gov.ru](https://pd.rkn.gov.ru/) — обязательно с 30.05.2025 для всех операторов ПДн, включая физлиц.
- Пересмотреть Политику конфиденциальности и Согласие после смены инфраструктуры.

**Пока сайт работает как есть**, риск минимальный (нулевой трафик, физлицо, ничтожный объём данных), но перед публичным продвижением или запуском платного трафика вопрос закрыть обязательно.

## Средний приоритет

### Перенести CSP из `<meta>` в HTTP-заголовок

Сейчас CSP объявлен в `<meta http-equiv="Content-Security-Policy">` в `index.html`. Директивы `frame-ancestors` и `report-uri` в meta-теге игнорируются браузерами. Правильнее вынести весь CSP в `public/_headers` (Cloudflare Pages HTTP-заголовки). Заодно удалить дублирующийся `<meta http-equiv="X-Content-Type-Options">` — он уже есть в `_headers`.

### Убрать мёртвый `<link rel="stylesheet" href="/src/style.css">` из `index.html`

Vite обрабатывает CSS через `import "./style.css"` в `main.js`. HTML-тег `<link>` при multi-page build теперь дублируется в бандл или ссылается на несуществующий путь в prod. Проверить и удалить.

### Заменить Three.js на vanilla Canvas 2D

Bundle 580KB / 164KB gzip почти весь из Three.js. Constellation по факту 2D (камера на Z=22, глубина не используется). Переписать на чистый Canvas 2D — снимет ~150KB gzip.

### Согласовать CTA с продуктом

Кнопки «Разобрать мою систему» / «Начать с диагностики» звучат как быстрая бесплатная сессия, а в услугах «Диагностика системы — 2–3 недели» — платный формат. Добавить тир бесплатного 30-минутного разбора или переформулировать CTA.

### Обернуть `initHero` в try/catch

Если WebGL заблокирован (старый браузер, приватный режим iOS с отключённым WebGL), `initHero(canvas)` бросит exception на топ-уровне модуля → сломается вся дальнейшая JS-инициализация, включая intro-таймлайн GSAP → hero-текст останется на `opacity: 0`.

### Настроить git identity

Коммиты сейчас идут от `ABRA CADABRA <abracadabra@MacBook-Air-ABRA.local>` — хостнейм с ноутбука в публичной истории. Настроить `git config user.name/user.email` под нормальные значения (например `Артём Утяшев <artemutyashev@gmail.com>`).

### Запинить `three` точной версией

`"three": "^0.161.0"` — caret на 0.x версии по semver может подтянуть 0.161.999 с потенциальным breaking change. Заменить на точную версию `"0.161.0"`.

## Низкий приоритет

### Node.js версия

Локально стоит Node 21.1.0 — нечётные версии не LTS. Vite 6.4.3 требует `^18 || ^20 || >=22`. CI использует Node 20. Разъезд «работает у меня — падает в CI» когда-нибудь случится. Обновиться на Node 22 LTS через nvm или brew.

### Sitemap.xml

`robots.txt` есть, а `sitemap.xml` — нет. Для одностраничника не критично, но с ростом количества страниц (напр. добавятся кейсы или блог) уже пригодится.

### Тестовое покрытие

Нет ни одного теста. Контактная форма — бизнес-критична; одна опечатка в JSON-хедере, и сабмиты тихо перестают доходить. Хотя бы smoke-тест для формы через Playwright / Cypress.

### Убрать `.claude/launch.json` из репо

Файл специфичен для Claude Code, никому другому не нужен. Добавить `.claude/` в `.gitignore`.
