# ABRAXUS STANDARD — установка и удаление

Скин — один файл `abraxus.yaml`. Установка копирует его в `~/.hermes/skins/`, удаление его убирает. Hermes, `app.asar` и чужие скины (в том числе пак в `~/.hermes/skins/`) не затрагиваются.

Команды ниже — для профиля по умолчанию (`~/.hermes`). Для другого профиля замените `~/.hermes` на `~/.hermes/profiles/<имя>`.

## 0. Проверить перед установкой

```bash
~/.hermes/hermes-agent/venv/bin/python ~/Documents/abrasite/hermes-theme/standard/check.py
```

Должно закончиться строкой `OK: 0 ошибок`. Проверка грузит скин настоящим движком Hermes во временной папке — рабочий `~/.hermes` она не трогает.

## 1. Убедиться, что место свободно

```bash
ls ~/.hermes/skins/abraxus.yaml
```

Ответ «No such file» — можно ставить. Если файл есть, сначала посмотрите, что в нём, и не перезаписывайте вслепую.

## 2. Запомнить текущий скин и сделать копию конфига

```bash
grep -n "skin:" ~/.hermes/config.yaml
```

```bash
cp ~/.hermes/config.yaml ~/.hermes/config.yaml.bak-abraxus
```

Сейчас там `skin: retro-mac` — к нему и будем откатываться.

## 3. Скопировать скин

```bash
cp ~/Documents/abrasite/hermes-theme/standard/abraxus.yaml ~/.hermes/skins/abraxus.yaml
```

После копирования ничего не меняется: скин лежит, но не включён.

## 4. Включить

**Попробовать на одну сессию** — в классическом CLI или TUI набрать `/skin abraxus`. Работает до выхода из сессии, конфиг не меняется. Desktop при этом не переключится: он узнаёт о YAML-скине, только когда тот станет активным в конфиге.

**Сделать скином по умолчанию** — для CLI и TUI:

```bash
hermes config set display.skin abraxus
```

Что увидите:

- **CLI** (`hermes`) — знак и надпись ABRAXUS в баннере при ширине окна от 95 колонок, медное приглашение `›`, ответы в рамке `[ .ABRAXUS ]`. Фон CLI не перекрашивает — нужен тёмный профиль терминала.
- **TUI** (`hermes --tui`) — то же, плюс TUI сам красит фон терминала в `#0C0B09` и возвращает прежний при выходе.
- **Desktop** хранит свой выбор темы отдельно и при запуске конфиг не читает, если тема в нём уже выбрана. Перекрасить его на лету может только событие gateway о смене скина, и оно доходит не всегда. Надёжный путь — включить вручную: набрать `/skin abraxus` в поле ввода Desktop или выбрать Settings → Appearance → **Abraxus**. Если пункта нет, перезапустите Desktop (⌘Q и открыть снова): при старте он подхватит `abraxus` из конфига. Выбор сохраняется. В Desktop будут графитовый фон, медь и приглушённые линии; брендинга, логотипа и шрифтов у STANDARD там нет, это EXTENDED.

## 5. Откатиться на прежний скин

```bash
hermes config set display.skin retro-mac
```

CLI/TUI переключатся при следующем запуске. В Desktop тему выберите вручную: `/skin <имя>` или Settings → Appearance. Если что-то пошло не так с самим конфигом — вернуть копию:

```bash
cp ~/.hermes/config.yaml.bak-abraxus ~/.hermes/config.yaml
```

## 6. Удалить

Сначала откатитесь (шаг 5) — иначе Hermes молча упадёт на скин по умолчанию. Затем:

```bash
rm ~/.hermes/skins/abraxus.yaml
```

Desktop кэширует пересчитанные YAML-скины в своём localStorage, поэтому пункт **Abraxus** может остаться в Appearance и после удаления файла. Он безвреден (рисует сохранённую палитру), штатной кнопки удаления для таких записей в Hermes нет. Имя `abraxus` не меняем между версиями, чтобы записи не копились.

## 7. Обновить до новой версии

Повторить шаги 0 и 3 (с перезаписью). Если `abraxus` активен, gateway сообщит Desktop об изменении файла. Если Desktop не перекрасился, перезапустите его.

## Побочный эффект: имя в релее ботов

`branding.agent_name` Hermes передаёт в релей ботов как отображаемое имя агента (`gateway/relay/__init__.py`). Со стоковым «Hermes Agent» имя не передаётся вовсе, с любым своим — передаётся, и в многоагентном чате ответы получат префикс «**ABRAXUS:**». В одиночном чате префикса нет.

Отключить передачу, оставив брендинг в терминале, нельзя: пустая переменная окружения не работает, Hermes тогда берёт имя из скина. Можно только задать для релея другое имя — переменная перекрывает скин:

```bash
grep GATEWAY_RELAY_DISPLAY_NAME ~/.hermes/.env
```

Если строки нет, добавить нужное имя, например:

```bash
echo 'GATEWAY_RELAY_DISPLAY_NAME=Артём' >> ~/.hermes/.env
```

Gateway прочитает её при следующем запуске.
