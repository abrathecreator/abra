ABRAXUS STANDARD v1.0

Фирменный YAML-скин Hermes на дизайн-токенах a-bra.ru. Только штатный механизм: без customCSS, без плагинов, без правки Hermes. Цвета на этой странице — снимок tokens.json и того, что настоящие конвертеры Hermes 489c1ac вывели из abraxus.yaml. Шрифты здесь браузерные: в терминале будет шрифт вашего профиля, а в Desktop — системный (YAML шрифтов не задаёт).

Палитра

Пятнадцать цветов, которые реально стоят в скине. Все из tokens.json: значения сайта и их смеси «цвет поверх фона × alpha», как блок [SHEETS] в abra-tokens.css. Новых цветов нет.

CLI — классический интерфейс hermes

Баннер при ширине терминала ≥ 95 колонок: слева знак (banner_hero), сверху надпись (banner_logo). Фон терминала CLI не перекрашивает — нужен тёмный профиль.

 Терминал — hermes

TUI hermes --tui

TUI сам красит фон терминала в #0C0B09 (OSC 11) и возвращает исходный при выходе. Подпись под логотипом и значок ☤ зашиты в Hermes и скином не меняются. Линии ui_border TUI поднимает до порога видимости: #2B2927 → #413F3D.

 Терминал — hermes --tui

Desktop Settings → Appearance → Abraxus

Desktop берёт из YAML семь ключей (background, ui_text, ui_accent, ui_border, banner_dim, ui_error, completion_menu_bg) и выводит остальное смешиванием. Брендинг, логотип и спиннер в Desktop не отображаются — это задача EXTENDED. Кнопка «громкой» заливки затемнена самим Hermes до #935C29 ради белого текста.

Варианты брендинга

В скин входит один вариант, рамкой отмечен вариант по умолчанию. Переключение — заменой строк в branding.

Варианты приветствия

welcome выводит только классический CLI при запуске. TUI и Desktop его не показывают.

Варианты спиннера

Скин задаёт «лица» и глаголы (выбираются случайно на каждый шаг) и «крылья». Сама анимация кадров ⠋⠙⠹ зашита в Hermes. Крылья видны только у «сырого» спиннера (например, hermes chat -q), в интерактивном CLI и в TUI статус выглядит как «лицо + глагол». Desktop эти тексты не показывает.
