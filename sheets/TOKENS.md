# ABRA — дизайн-токены для Google Таблиц

Перенос дизайн-системы сайта `a-bra.ru` в Google Sheets. Источник значений —
`abra-tokens.css` (блоки `[AS-BUILT]` и `[TARGET]`). **Новых цветов здесь нет**:
всё, чего в токенах не было, получено композитингом существующих токенов
(rgba поверх фона), потому что Google Sheets не умеет прозрачность — только
непрозрачные HEX.

Формула композитинга: `результат = фон + (цвет − фон) × alpha`.

---

## 1. Тема таблицы (Формат → Тема → Настроить)

Это единственный «токенный» слой, который есть в Sheets нативно: он красит
шапки, ссылки и **серии в диаграммах** во всём файле. Настраивать один раз.

### Тёмная тема — «сайт»

| Слот темы   | HEX       | Токен-источник        |
|-------------|-----------|-----------------------|
| Шрифт       | `Inter`   | `--abra-font-body`    |
| Текст       | `#EDEBE6` | `--abra-text`         |
| Фон         | `#0C0B09` | `--abra-bg`           |
| Акцент 1    | `#B87333` | `--abra-accent`       |
| Акцент 2    | `#C9C3BB` | `--abra-prose`        |
| Акцент 3    | `#8A5637` | `--abra-accent-dim`   |
| Акцент 4    | `#8C857D` | `--abra-muted`        |
| Акцент 5    | `#D0A984` | медь + текст 45 % *   |
| Акцент 6    | `#5E574F` | `--abra-faint`        |
| Ссылка      | `#B87333` | `--abra-accent`       |

\* `#D0A984` = `--abra-accent` смешанная с `--abra-text` на 45 % — тинт меди,
а не новый цвет. Нужен, чтобы в диаграмме было 6 различимых серий.

Логика ряда акцентов: **медь = главная серия, всё остальное — нейтральная
серо-тёплая шкала.** Не раскрашивать серии произвольно — на сайте цвет один,
и в отчёте он тоже должен означать «смотри сюда».

### Светлая тема — «печать / клиентский отчёт»

Для того, что уходит клиенту в PDF или на печать. Тёмный фон в печать не годится.

| Слот темы | HEX       | Токен-источник        |
|-----------|-----------|-----------------------|
| Шрифт     | `Inter`   | `--abra-font-body`    |
| Текст     | `#1A1512` | `--abra-sheet-ink`    |
| Фон       | `#EFEAE2` | `--abra-sheet`        |
| Акцент 1  | `#B87333` | `--abra-accent`       |
| Акцент 2  | `#1A1512` | `--abra-sheet-ink`    |
| Акцент 3  | `#8A5637` | `--abra-accent-dim`   |
| Акцент 4  | `#5E574F` | `--abra-faint`        |
| Акцент 5  | `#D0A984` | медь + текст 45 %     |
| Акцент 6  | `#8C857D` | `--abra-muted`        |
| Ссылка    | `#8A5637` | `--abra-accent-dim`   |

**Важно:** на светлом фоне `#B87333` даёт 3,17:1 — этого мало для текста.
Поэтому медный **текст** на светлом — только `#8A5637` (5,06:1), а `#B87333`
остаётся для заливок, линий и диаграмм.

цифры ниже нормы AA, поэтому красить им цифры нельзя.

## 3. Типографика

| Слой                         | Шрифт   | Размер | Начертание |
|------------------------------|---------|--------|------------|
| Название листа / H1 в ячейке | Syne    | 18–20  | Bold       |
| Метка раздела `[ .Название ]`| Syne    | 10     | Medium     |
| Шапка таблицы                | Syne    | 10     | Bold, ВЕРХНИЙ РЕГИСТР |
| Текст, подписи               | Inter   | 10     | Regular    |
| **Все числа без исключения** | Inter   | 10     | Regular / Bold для итогов |

Оба шрифта ставятся один раз: **Шрифт → Другие шрифты → найти Syne / Inter**.

**Цифры Syne не использовать нигде.** Это не вкусовщина: у Syne неровные штрихи
на цифрах, разновысокие 5 и 0, и знак ₽ съезжает с базовой линии — ровно из-за
этого на сайте живёт подмена шрифта `AbraNumerals`. В Таблицах такой подмены
нет, поэтому правило простое: **Syne только для буквенных заголовков.**

Метка раздела набирается фирменным форматом `[ .Воронка ]` — скобка, пробел,
точка вплотную к слову, пробел, скобка.

## 4. Числовые форматы (Формат → Числа → Свой формат)

Локаль файла обязательно: **Файл → Настройки → Регион: Россия** — иначе не будет
ни запятой в дробях, ни пробела в разрядах.

| Что                | Формат                          | Выглядит      |
|--------------------|----------------------------------|---------------|
| Деньги             | `#,##0" ₽"`                      | `1 240 000 ₽` |
| Деньги с копейками | `#,##0.00" ₽"`                   | `1 240,50 ₽`  |
| Деньги, минус      | `#,##0" ₽";−#,##0" ₽"`           | `−1 240 ₽`    |
| Проценты           | `0.0"%"`                         | `3,4%`        |
| Штуки              | `#,##0`                          | `12 480`      |
| **ROI**            | `0.00" ×"`                       | `3,54 ×`      |
| Дельта к периоду   | `+0.0"%";−0.0"%";0"%"`           | `+12,4%`      |

**ROI — кратность, не процент.** Формула `валовая прибыль / расходы на
привлечение` отвечает «во сколько раз», и `354,5 %` для той же величины читается
как «+354 % к вложенному» — это другое число. Нужен процент — переходи на ROMI
с формулой `(прибыль − затраты) / затраты` и переименовывай метрику. Смесь
недопустима. Это правило калькулятора юнит-экономики, оно же действует в таблицах.

Знак минуса — U+2212 (`−`), не дефис. ₽ отделён неразрывным пробелом (U+00A0).
Все числовые колонки — выравнивание **по правому краю**, текстовые — по левому.

## 5. Правила вёрстки листа

Главное, что делает таблицу похожей на сайт, — это не цвет, а **отсутствие сетки**.

1. **Вид → Показать → Сетка: выключить.** На сайте нет ни одной вертикальной
   линейки, только тонкие горизонтальные разделители.
2. Границы — только **нижняя** у строк, цветом `sheet.line`. Вертикальных нет.
3. Под шапкой — линия `sheet.accent` (медь), 1 px. Это единственное медное
   пятно в статике; всё остальное медное появляется только по условию.
4. Высота строк: **28 px** для данных, **34 px** для шапки. Дефолтный 21 px
   слишком плотный для этой типографики.
5. Полосатость строк — `sheet.bg` / `sheet.bg-band`. Разница между ними
   минимальная (`#0C0B09` / `#131210`), и это правильно: полоса должна
   угадываться, а не рябить.
6. Закрепить строку шапки (Вид → Закрепить → 1 строка).
7. Отступ первой колонки: пустая колонка A шириной **32 px** — эквивалент
   `--gutter` сайта. Данные начинаются с B.
8. Итоговая строка — `sheet.text-strong` + Bold + верхняя граница `sheet.line-strong`.
9. Один акцент на экран. Если медью подсвечено больше 2–3 ячеек, подсветка
   перестала что-либо значить.

## 6. Условное форматирование

Сдержанный вариант по умолчанию (рекомендуется для клиентских отчётов):

| Условие                  | Заливка              | Текст            |
|--------------------------|----------------------|------------------|
| Целевое значение достигнуто | `sheet.fill-accent` | `sheet.text-strong` Bold |
| Требует внимания         | нет                  | `sheet.accent`   |
| Норма                    | нет                  | `sheet.text`     |

Расширенный вариант — для внутренних рабочих листов, где нужен светофор:
`sheet.fill-ok` / `sheet.fill-warn` / `sheet.fill-bad` как заливки, текст всегда
`sheet.text`. В клиентские отчёты светофор лучше не тащить — на сайте цвет
ровно один, и три новых значения цвета ломают этот язык.

Цветовая шкала (градиент) — от `sheet.bg` к `sheet.fill-accent`, средняя точка
не задаётся.

## 7. Как применить

Вручную — по разделам 1, 3, 4, 5 выше. Автоматически — скрипт
[`abra-theme.gs`](abra-theme.gs): Расширения → Apps Script, вставить файл,
сохранить, перезагрузить таблицу. В меню появится **ABRA**.
